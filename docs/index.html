Kavşağınızı dinleyen canlı trafik sayacı

Haritada kavşak kollarını işaretleyin; uygulama gerçek yol mesafesi ve canlı trafik hızından geçen araç sayısını, kuyruk yükünü ve saatlik toplamları hesaplasın. Sonuçlar Excel raporu olarak iner.

Nasıl kullanılır?

Kurulumdan sonra tüm iş akışı üç adımda tamamlanır.

  1. Yolun şerit yönüne tıklayın Haritada yolun/şeridin üzerine, o kolun gidiş yönünde tıklamanız yeterli. Her tıklama bir kol noktası ekler ve noktanın altındaki cadde adı otomatik bulunur. Kavşağın 3–4 kolu için birer kez tıklayın.
  2. Kolları ekleyip sağlayıcıyı seçin "Kolları Ekle" ile noktalar kola dönüşür ve gerçek yönlerine göre adlandırılır. Ücretsiz kullanım için OSRM; TomTom / HERE / Google için API anahtarı girin.
  3. İzlemeyi başlatın ve raporu indirin Panel 5–60 saniyede bir güncellenir. "Excel'e Aktar" ile saat bazlı sayım, cadde özeti, ham loglar ve pivot tablo içeren dosyayı alırsınız.

Özellikler

Ücretsiz OSRM verisiyle çalışır; API anahtarı girildiğinde canlı trafik hızına geçer.

🗺️

Gerçek yol ağı

OSRM Table API ile tüm kollar arasında mesafe/süre matrisi ve rota geometrisi tek istekte alınır.

📡

Canlı trafik

TomTom, HERE ve Google Routes desteği. Anahtar yoksa veya servis düşerse otomatik OSRM'e döner.

🚗

Hıza bağlı sayım

Greenshields temel diyagramı: yavaşlayan kolda yoğunluk artar, akış tepe yapar, kilitlenmede düşer.

🚦

Sinyal faktörü

Sinyalize kavşakta %45 yeşil süre payı, sinyalsizde kesintisiz geçiş; çalışırken anında değiştirilebilir.

📊

Excel + pivot

Saat bazlı sayım, cadde özeti, özet, ham loglar ve gerçek pivot tablo tek dosyada.

💾

SQLite kayıt

60 saniyelik pencerelerde biriken araç toplamları kalıcı olarak saklanır.

API uç noktaları

Panelin tamamı bu JSON API üzerinden çalışır; kendi arayüzünüzü de bağlayabilirsiniz.

MetotYolAçıklama
POST/api/detectİşaretlenen noktalardan kolları tespit eder
POST/api/startİzlemeyi başlatır (coords, provider, api_key, signalized)
POST/api/stopİzlemeyi duraklatır, kollar korunur
GET/api/statusCanlı durum, kollar, sayaçlar, saatlik veriler
GET/api/exportDetaylı Excel (log + saatlik + pivot)
GET/api/reportSaatlik özet Excel raporu
